How it works

Model Viewer supports iOS and Android, but iOS hands the scene to Quick Look. Babylon.js keeps the camera and model in the web page, but requires WebXR (normally Android Chrome). Camera permission is requested only after you press an AR button.

Repeatable comparison

Run the same movement test

  1. Place the same model on a clearly textured, stationary surface.
  2. Walk one full circle around it while keeping it in frame.
  3. Move 2–3 metres away, return, and briefly point the camera elsewhere.
  4. Compare drift, jitter, scale changes, and whether the model returns to the same spot.

Keep conditions equal: use the same device, room, lighting, surface, model, and path for every library.
